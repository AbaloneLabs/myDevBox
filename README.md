# MyDevBox

> 샌드박스 내에서 AI 에이전트와 함께 개발하는 차세대 로컬 개발 환경

MyDevBox는 웹 서버 기반으로 동작하는 로컬 개발 환경으로, 격리된 샌드박스 컨테이너 안에서 코드를 작성하고 AI 에이전트와 채팅하며 개발을 진행할 수 있습니다. 코드 에디터와 에이전트 채팅을 결합한 하이브리드 모드와, 에이전트와의 대화에만 집중하는 바이브 코딩 모드를 모두 지원합니다.

## 핵심 특징

| 특징 | 설명 |
|------|------|
| **샌드박스 내 개발** | 격리된 컨테이너 환경에서 안전하게 코드를 실행·빌드·테스트 |
| **할 일(Tasks) 관리** | 개발 작업을 체계적으로 추적하고 우선순위를 관리 |
| **문서(Docs) 자동 생성** | 코드베이스 분석을 통해 문서를 자동으로 생성·갱신 |
| **계획(Plans) 관리** | 구조화된 계획 문서를 작성하고 버전별로 관리 |
| **경량 웹 브라우저 지원** | 개발 중인 앱을 샌드박스 내에서 즉시 미리보기 |
| **에이전트 채팅** | AI 에이전트와 자연어로 소통하며 개발 진행 |

## 두 가지 작업 모드 (에디터 토글)

두 모드는 서로 다른 레이아웃이 아니라, **하나의 동일한 레이아웃에서 코드 에디터 패널의 가시성(show/hide)만 토글**하는 방식으로 동작합니다. 이를 통해 열린 파일, 채팅 히스토리, 에이전트 상태 등 모든 컨텍스트가 전환 중에 유지됩니다.

```
┌──────────────────────────────────────────────────────┐
│  [ Top Bar: Mode Toggle | Tasks | Plans | Docs ]     │
├───────────────────────────┬──────────────────────────┤
│                           │                          │
│   Code Editor (Monaco)    │    Agent Chat            │
│   [ 토글로 show/hide ]     │    (항상 표시)            │
│                           │                          │
└───────────────────────────┴──────────────────────────┘
```

### 모드 1: Developer Mode (에디터 표시)
에디터 패널이 표시됩니다. 좌측에서 직접 코드를 작성하고, 우측 에이전트 채팅으로 도움을 받는 전통적인 개발자 워크플로우입니다.

### 모드 2: Vibe Mode (에디터 숨김, 바이브 코딩)
에디터 패널이 숨겨지고 채팅이 전체 폭을 차지합니다. 에이전트가 코드 작성·실행·수정을 주도하고, 사용자는 대화로 방향을 제시합니다. 코드 변경 사항은 채팅 내에 diff로 표시됩니다.

두 모드는 상단 토글 버튼이나 단축키(`Cmd/Ctrl + Shift + V`)로 언제든 즉시 전환할 수 있습니다.

## 기술 스택

- **백엔드**: Node.js + TypeScript + Express/Fastify (비동기 WebSocket 기반 에이전트 통신)
- **프론트엔드**: React + TypeScript + Vite
- **코드 에디터**: Monaco Editor (VS Code 동일 엔진)
- **샌드박스**: Docker 컨테이너 (격리된 실행 환경, Docker SDK 연동)
- **데이터베이스**: SQLite (할 일, 계획, 문서 메타데이터)
- **실시간 통신**: WebSocket

> **풀스택 TypeScript**: 백엔드와 프론트엔드를 모두 TypeScript로 통일하여 API 스키마, WebSocket 메시지 타입, 에이전트 도구 정의를 양쪽에서 공유합니다. 이는 Claude Code(Anthropic), Codex CLI(OpenAI) 등 주요 코딩 에이전트가 채택한 방식입니다.
